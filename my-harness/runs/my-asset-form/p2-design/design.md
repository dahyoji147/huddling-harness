# 화면 설계
## 내 자산 등록

화면 이름은 "내 자산 등록"이다. 유료 멤버가 만든 프롬프트, 스킬 파일, 자동화 템플릿, 사용 사례를 내 자산으로 등록하는 390×844 모바일 화면 1장이다. 프레임은 기본 상태(제목과 카테고리 입력 완료, 공개 범위 비공개, 바텀시트 닫힘) 하나만 그린다.

### 1. 프레임과 정보 구조

프레임은 390×844, 채움 canvas #ffffff, 좌우 여백 16이다. 위에서 아래로 영역이 다음 순서로 쌓인다. 좌표는 프레임 기준 y이다.

| # | 영역 | y 범위 | 높이 | 내부 간격 |
|---|------|--------|------|-----------|
| 0 | 상태 표시줄 영역(시스템 영역, 빈 canvas) | 0–44 | 44 | 내용 없음 |
| 1 | 상단 바 | 44–92 | 48 | 좌우 16 |
| 2 | 본문 영역(세로 스크롤, 프레임에서는 클립) | 92–653 | 561 | 위 16, 항목 사이 24 |
| 3 | 하단 고정 영역 | 653–844 | 191 | 아래 항목 참고 |

하단 고정 영역(653–844) 내부는 다음과 같다. 영역에 구분선과 그림자는 없고 canvas 채움이다.
- 위 패딩 12 (653–665)
- 공개 범위 행 665–721 (높이 56)
- 간격 8
- 유의 문구 729–746 (높이 17)
- 간격 12
- 하단 고정 버튼 758–810 (높이 52, 너비 358)
- 홈 인디케이터 여백 810–844 (34)

본문 영역(92–653) 안의 항목 배치는 다음과 같다. 항목 사이 간격은 모두 24이고, 라벨과 입력 사이는 8이다.

| 순서 | 항목 | y 범위 | 높이 | 구성 |
|------|------|--------|------|------|
| 1 | 제목 | 108–181 | 73 | 라벨 17 + 8 + 입력 48 |
| 2 | 설명 | 205–302 | 97 | 라벨 17 + 8 + 입력 72 |
| 3 | 카테고리 | 326–423 | 97 | 라벨 17 + 8 + 칩 2줄(32 + 8 + 32) |
| 4 | 태그 | 447–600 | 153 | 라벨 17 + 8 + 입력 48 + 8 + 추천 칩 줄 32 + 8 + 선택 칩 줄 32 |
| 5 | 파일 첨부 | 624–786 | 162 | 라벨 17 + 8 + 첨부 행 48 + 8 + 미리보기 행 56 + 8 + 안내 17 |
| 6 | 사용 방법 | 810–931 | 121 | 라벨 17 + 8 + 입력 96 |
| 7 | 예시 결과 | 955–1076 | 121 | 라벨 17 + 8 + 입력 96 |

- 본문 콘텐츠는 y=92부터 1100까지(끝 패딩 24 포함)이고, 본문 컨테이너(y 92–653, 높이 561)가 클립한다(clipsContent). 완성 프레임은 390×844 하나이고 프레임 밖으로 나가는 레이어는 없다.
- 프레임에서 항목 1~4는 완전히 보인다. 항목 5(파일 첨부)는 y=653에서 잘려 라벨과 첨부 행 윗부분만 보인다. 이것이 아래로 더 스크롤된다는 단서이다.
- 항목 5~7은 본문 컨테이너 안에 같은 규칙으로 만들어 두되, 클립 때문에 보이지 않는 부분은 보이지 않는 것이 정상이다.
- 공개 범위 행은 본문이 아니라 하단 고정 영역에 있어 스크롤과 관계없이 항상 보인다. 맨 아래 한 행이라는 위치를 지키면서 프레임에 반드시 보이게 하기 위해서다.
- 하단 고정 영역과 본문은 서로 겹치지 않는다. 본문 클립 선이 하단 고정 영역의 윗변(y=653)이다.

### 2. 입력 항목

필수 표시는 라벨 오른쪽에 붙는 작은 텍스트 "필수"(caption 12/400, text-muted)로만 한다. 선택 항목에는 표시를 붙이지 않는다.

| 항목 | 필수/선택 | 라벨 | 플레이스홀더 | 기본 프레임 표시 |
|------|-----------|------|--------------|------------------|
| 제목 | 필수 | 제목 + "필수" | 자산 이름을 입력해 주세요 | 값 "내 프롬프트 모음"(ink) |
| 설명 | 선택 | 설명 | 어떤 자산인지, 어디에 쓰면 좋은지 적어 주세요 | 플레이스홀더(text-faint) |
| 카테고리 | 필수 | 카테고리 + "필수" | 없음(선택 칩) | "프롬프트" 칩 선택됨 |
| 태그 | 선택 | 태그 | 태그를 입력하고 추가해 주세요 | 플레이스홀더, 선택 칩 2개 |
| 파일 첨부 | 선택 | 파일 첨부 | 첨부 행 문구 "파일 선택하기" | 첨부 행 + 미리보기 행 1개 |
| 사용 방법 | 선택 | 사용 방법 | 사용하는 순서를 간단히 적어 주세요 | 플레이스홀더 |
| 예시 결과 | 선택 | 예시 결과 | 이 자산으로 얻은 결과 예시를 적어 주세요 | 플레이스홀더 |
| 공개 범위 | 필수(기본값 있음) | 공개 범위 | 없음 | 현재값 "비공개" |

- 카테고리 칩은 "프롬프트", "스킬 파일", "자동화 템플릿", "사용 사례", "기타" 5개이다. 1줄에 프롬프트, 스킬 파일, 자동화 템플릿, 2줄에 사용 사례, 기타를 놓는다. 칩 사이 가로 8, 줄 사이 8이고 단일 선택이다.
- 태그 추천 칩은 가로 스크롤 한 줄이고 우측 화면 밖으로 이어진다. 칩은 "바이브코딩", "QA", "회의록", "보고서", "템플릿" 순서이다. 추가한 태그는 추천 줄 아래 선택 칩 줄에 "업무자동화 ✕", "문서작성 ✕" 2개로 쌓는다.
- 파일 첨부는 첨부 행 아래에 미리보기 행 1개를 둔다. 미리보기 행은 파일명 "프롬프트 모음.md"(body 15/400), 크기 "12KB"(caption, text-muted), 오른쪽 제거 버튼(X)으로 구성한다. 그 아래 한 줄 안내(caption, text-muted)는 "md, txt, pdf, zip · 파일당 10MB 이하"이다. 허용 형식과 용량은 가정값이며 구현 때 서비스 기준으로 확정한다.
- 사용 방법, 예시 결과 아래에는 안내 한 줄(caption, text-muted)을 둔다: "개인정보, 고객정보, 회사 기밀, 타인의 저작물은 넣지 말아 주세요". 이 줄은 본문 클립 아래라 프레임에서는 보이지 않아도 노드로 만든다.
- 라벨은 label 토큰(12/600, ink)이다.

### 3. 공개 범위

- 폼 하단(하단 고정 영역)에 한 행으로 둔다. 행 노드 이름은 정확히 `공개범위/기본=비공개`이다.
- 행은 높이 56, 너비 358, 채움 canvas-soft #f3f3f3, 모서리 9999(pill), 테두리 없음이다. 좌우 패딩 24이다. 왼쪽에 "공개 범위"(body 15/400, text-muted)를, 오른쪽에 현재값 "비공개"(link 15/600, ink)와 오른쪽 화살표 아이콘(chevron-right 16, ink)을 둔다.
- 기본값은 비공개이다. 이 프레임에는 기본 상태(비공개 선택, 바텀시트 닫힘)만 그린다.
- 행을 탭하면 바텀시트가 열린다(이 프레임에는 그리지 않는 구조 명세).
  - 시트: canvas 채움, 위쪽 모서리 24, 그림자 없음, 뒤는 ink 40% 불투명도 딤. 제목 "공개 범위"(heading-4).
  - 선택지는 라디오 리스트이다. 행당 높이 56, 선택지 문구는 "비공개", "멤버 공개", "판매 신청"이고, 각 행에 보조 설명 한 줄(caption, text-muted)을 붙인다.
  - 보조 설명: 비공개 "나만 볼 수 있어요" / 멤버 공개 "허들링 멤버가 볼 수 있어요" / 판매 신청 "운영자 검수를 거쳐요".
  - 시트 하단 전폭 pill 확정 버튼 "선택하기"(button-primary)이다. 선택된 값이 있어야 활성이다.
- 역할별 규칙은 다음과 같다.
  - `seller` 역할: 세 값 모두 선택 가능하다.
  - 그 외 역할(유료 회원): "판매 신청" 행을 비활성(문구 text-faint, 라디오 비활성)으로 두고, 그 아래 사유 문구 "판매 승인 회원만 선택할 수 있어요"(caption, text-muted)를 함께 보여준다. 비활성 행은 탭해도 선택되지 않는다.
- 공개 범위 필드의 값은 사용자가 바꾸지 않으면 항상 비공개이다.

- 하단 고정 버튼의 활성 문구는 "등록하기"이다.
- 비활성 문구는 "제목을 입력해 주세요", "카테고리를 선택해 주세요"이다(위쪽 항목부터 안내).
- 기본 프레임은 제목과 카테고리가 채워져 있으므로 활성 상태(ink 채움)이다.
- 입력 필드 포커스 상태(text-input-focused)는 같은 모양에 2px ink 링을 더하며, 기본 프레임에는 나타나지 않는다.
- 유의 문구(notice-text)는 caption(12/400), text-muted, 좌우 16, 문구는 "등록한 뒤에도 내 자산에서 수정할 수 있어요"이다.
- 아이콘은 단색 ink 또는 text-muted로 한다.

### 7. 반영 포인트 대응표

| # | points.md 포인트 | 반영 영역 | 반영 여부 |
|---|------------------|-----------|-----------|
