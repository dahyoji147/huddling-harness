# 화면 설계

기존 "내 자산 등록" 한 화면(입력 7개)은 본문이 클립에 가려 보였다. 그래서 같은 입력을 두 화면으로 나눈다. 두 화면 모두 390×844 프레임 하나에 모든 내용이 잘림 없이 보이고, 스크롤 본문(clipsContent)으로 내용을 가리지 않는다. 완성 화면은 "내 자산 등록 1단계", "내 자산 등록 2단계" 2장이다.

### 공통 규칙

**프레임과 영역 순서.** 프레임은 390×844, 채움 canvas #ffffff, 좌우 여백 16이다. 위에서 아래로 상태 표시줄(44) / 상단 바(48) / 본문 / 하단 고정 영역이 쌓인다. 본문은 클립하지 않는 일반 프레임(clipsContent=false)이다. 본문 안 모든 노드의 아래쪽 끝은 본문 영역의 아래쪽 끝 이하이고, 본문 아래쪽 끝은 하단 고정 영역의 윗변과 같거나 위에 있다. 프레임 밖으로 나가는 레이어는 없다. 가로 스크롤 줄과 세로 스크롤 본문은 쓰지 않는다. 좌표 y는 프레임 기준이다.

**상단 바(두 화면 공통).** 상단 바 인스턴스(top-bar, 390×48, y 44–92)의 제목은 "내 자산 등록"(heading-4, 가운데)이다. 뒤로 버튼(icon-button 40×40)은 x 16, y 48–88이다. 단계 표시(step-indicator)는 상단 바 위에 겹쳐 놓는 형제 인스턴스이고(부모는 화면 프레임), 크기 54×28, x 320–374, y 54–82이다. 제목은 가운데(x 약 145–245)라 단계 표시와 겹치지 않는다.

**새 컴포넌트: 단계 표시(step-indicator).** 크기 54×28, 모서리 9999(radius-9999), 채움 canvas-soft(변수 바인딩), 테두리와 그림자 없음. 글자 label 토큰(12/600), ink, 가운데 정렬, 좌우 패딩 12. 문구는 인스턴스 텍스트로 "1 / 2", "2 / 2"를 바꾼다. 새 컴포넌트는 이것 하나뿐이다.

**재사용 컴포넌트와 override.** top-bar, icon-button, text-input, chip/미선택, chip/선택, chip-tag-selected, file-attach-row, file-preview-row, visibility-row, button-primary, button-primary-disabled, notice-text 12개는 기존 그대로 인스턴스로 쓴다. 이번 설계는 입력 높이 override를 쓰지 않는다(설명 72, 사용 방법·예시 결과 96 기본 높이 그대로 들어간다). 바꾸는 것은 인스턴스 텍스트(문구)뿐이고, 노드 이름은 컴포넌트 이름을 유지하되 공개 범위 행만 `공개범위/기본=비공개`로 한다.

**토큰.** 글꼴 Pretendard(구현 시 Noto Sans KR 대체). 색은 ink #141414, canvas #ffffff, canvas-soft #f3f3f3, field #f0f0f0, hairline #e0e0e0, text-muted #707070, text-faint #adadad, on-primary #ffffff이고 모든 채움과 글자색은 tokens/color 변수에 바인딩한다. 모서리 0/16/24/9999(tokens/radius), 간격 4/8/12/16/24/32/48(tokens/spacing). 글꼴 스타일은 heading-4(18/700), body(15/400), link(15/600), label(12/600), caption(12/400)만 쓴다. 필수 표시는 라벨 오른쪽 작은 텍스트 "필수"(caption, text-muted)이고 선택 항목에는 붙이지 않는다. 입력 항목 라벨, 플레이스홀더, 필수 여부는 기존 설계 §2를 그대로 쓴다.

**키스크린 3장(이후 단계에서 만든다).** ① `내 자산 등록 1단계 기본` ② `내 자산 등록 2단계 기본` ③ `공개 범위 선택 (유료 회원)`. ①②는 완성 화면과 같은 레이아웃의 기본 상태이고, ③은 2단계 화면 위에 딤과 바텀시트를 얹은 상태이다. 바텀시트는 키스크린이라 완성 화면 목록에 포함하지 않는다.

## 내 자산 등록 1단계

### 1단계 목적과 구성

기본 정보를 받는 화면이다. 제목(필수), 설명(선택), 카테고리(필수), 태그(선택)와 하단 고정 "다음" 버튼으로 구성한다. 공개 범위 텍스트와 필드는 이 화면에 넣지 않는다(2단계에 있다). 프레임 이름은 `내 자산 등록 1단계`, 상단 바 단계 표시는 "1 / 2"이다. 기본 상태는 제목 "내 프롬프트 모음"(ink), 카테고리 "프롬프트" 칩 선택, 태그 선택 칩 2개(업무자동화 ✕, 문서작성 ✕), 설명은 플레이스홀더이다.

가로 배치(x, 좌우 여백 16, 칩 사이 8): 칩 가로는 글자 + 좌우 16이다. 카테고리 1줄은 약 90+8+82+8+110으로 358 이내이다. 태그 추천 1줄(바이브코딩, QA, 회의록)은 약 92+8+48+8+68, 2줄(보고서, 템플릿)과 선택 칩 줄(업무자동화 ✕ 약 112, 문서작성 ✕ 약 100)도 358 이내이다. 칩이 넘치지 않도록 줄을 위처럼 고정한다.

### 1단계 상태와 문구

하단 버튼은 활성 "다음"(ink 채움, on-primary 글자, link 15/600)이다. 필수 항목이 비면 button-primary-disabled(hairline 채움, text-muted)로 바꾸고 문구를 "제목을 입력해 주세요", 그다음 "카테고리를 선택해 주세요"로 둔다(위쪽 항목부터 안내). 기본 프레임은 제목과 카테고리가 채워져 활성이다. 카테고리는 단일 선택, 칩 5개는 프롬프트, 스킬 파일, 자동화 템플릿, 사용 사례, 기타이다. 선택 칩은 chip/선택(ink), 미선택은 chip/미선택(canvas-soft)이다. 태그는 칩 터치 시 입력창 위 추천에서 선택 칩으로 쌓이는 동작을 구현 메모로 둔다. 가로 스크롤은 쓰지 않는다.

## 내 자산 등록 2단계

### 2단계 목적과 구성

상세 내용과 공개 범위를 받는 화면이다. 파일 첨부(첨부 행, 미리보기 행, 안내 한 줄), 사용 방법, 예시 결과, 개인정보·저작물 금지 안내 문구, 공개 범위 행, 하단 고정 "등록하기" 버튼으로 구성한다. 프레임 이름은 `내 자산 등록 2단계`, 단계 표시는 "2 / 2"이다. 기본 상태는 파일 미리보기 행 1개("프롬프트 모음.md", "12KB", 제거 X), 사용 방법과 예시 결과는 플레이스홀더, 공개 범위 현재값 "비공개"이다. 선택 항목뿐이라 모두 비어 있어도 등록할 수 있고, 1단계 필수 값은 이미 채워진 상태로 넘어온다.

### 공개 범위 행과 안내

공개 범위 행은 높이 56, 너비 358, 채움 canvas-soft, 모서리 9999, 좌우 패딩 24, 테두리 없음이다. 기본값은 비공개이고 사용자가 바꾸지 않으면 항상 비공개이다. 탭하면 바텀시트가 열린다. 금지 안내 문구는 사용 방법과 예시 결과 바로 아래(8 간격)에 두어 입력 직후 읽히게 한다.

### 키스크린 ③ 공개 범위 선택 (유료 회원)

2단계 화면(기본 상태) 위에 딤과 바텀시트를 얹는다. 딤은 390×844 전체, ink 채움 40% 불투명도이다. 시트는 y 481–844(높이 363), 너비 390, canvas 채움, 위쪽 모서리 24, 아래쪽 0, 그림자 없음이다. 시트 내부 좌표는 다음과 같다. 위 패딩 24 → 제목 "공개 범위"(heading-4) 505–529 → 간격 16 → 라디오 행 세 개(행 높이 56, 좌우 16): 비공개 545–601, 멤버 공개 601–657, 판매 신청 657–713 → 간격 4 → 사유 문구 717–734 → 간격 24 → "선택하기" button-primary 358×52 y 758–810 → 여백 34(810–844). 합계 24+24+16+168+4+17+24+52+34 = 363, 481+363 = 844이다. 라디오는 지름 20 원이고(선택은 ink 채움과 가운데 on-primary 점 8, 미선택은 canvas-soft 채움, 비활성은 hairline 채움, 테두리 없음), 행마다 선택지 문구(body)와 보조 설명 한 줄(caption, text-muted)을 둔다. 보조 설명은 비공개 "나만 볼 수 있어요", 멤버 공개 "허들링 멤버가 볼 수 있어요", 판매 신청 "운영자 검수를 거쳐요"이다. 이 키스크린은 유료 회원이므로 현재 선택은 비공개이고, "판매 신청" 행은 문구와 라디오를 비활성(text-faint, hairline)으로 두며 그 아래 사유 문구 "판매 승인 회원만 선택할 수 있어요"(caption, text-muted)를 둔다. 비활성 행은 탭해도 선택되지 않는다. 판매 승인 회원(seller)용 시트는 그리지 않고 문장으로만 정한다. seller는 같은 시트에서 세 값을 모두 선택할 수 있고, 판매 신청 행은 활성 문구(ink)이며 사유 문구가 없어 그 자리만큼 시트가 17 낮아진다. "선택하기"는 선택된 값이 있어야 활성이다.
