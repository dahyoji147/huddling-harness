# 입력

## 화면 주제
내 자산 등록을 2단계로 나눈 화면 (PRD §6-5, §3-3·3-4). 한 화면에 입력 항목이 너무 많아 잘려 보이던 기존 "내 자산 등록"을 두 화면으로 나눈다.
- 1단계: 기본 정보 (제목, 설명, 카테고리, 태그). 하단 "다음" 버튼과 단계 표시(1 / 2).
- 2단계: 상세와 공개 범위 (파일 첨부, 사용 방법, 예시 결과, 공개 범위 행). 하단 "등록하기" 버튼과 단계 표시(2 / 2).
공개 범위는 비공개(기본) / 멤버 공개 / 판매 신청(판매 승인 회원만 선택 가능)이다.
두 화면 모두 390×844 안에 모든 내용이 잘림 없이 보여야 한다. (스크롤되는 본문 영역으로 내용을 가리지 않는다.)

## 화면 목록
- 내 자산 등록 1단계
- 내 자산 등록 2단계
