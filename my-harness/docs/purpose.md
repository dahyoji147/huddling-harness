| 항목 | 내용 |
|---|---|
| 매번 달라지는 것 | 화면 주제 (고정: `design.md`, PRD) |
| 사용자 | 허들링 디자이너 |
| 화면 목록 | 디자이너가 화면 주제와 함께 직접 입력한다. 기본 후보는 PRD §16의 핵심 화면 10개 |
| 완료 기준 | 화면 목록의 모든 화면이 390×844 Figma 완성본이고, `design.md`·★ 위반이 0건 |

## 완료 기준 (스크립트가 세는 형태)

| 기준 | 세는 방법 |
|---|---|
| 완성본 | 화면 목록의 N개 화면 모두 프레임 크기가 정확히 390×844 |
| `design.md` 위반 | 모서리 반경은 0/16/24/9999만 허용, 그림자 0개, `#0066ff`는 화면당 2개 이하, 글꼴은 Pretendard만(임시로 Noto Sans KR도 허용), 버튼은 전부 pill |
| ★ 위반 (A, 민감정보) | 화면의 모든 텍스트에서 이메일 형식, 전화번호 형식, 금지어(`rules.yaml`, 처음엔 비어 있음)가 0건 |
| ★ 위반 (B, 공개 범위) | "공개 범위" 필드가 있는 모든 화면에서 기본 선택값이 `비공개`가 아닌 것 0건 |

★ = `docs/story-service.md`의 "어기면 안 되는 것" A, B. 상세 규칙은 R4~R5에서 규칙 파일(SSOT)로 옮긴다.
